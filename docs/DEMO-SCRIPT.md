# Before — 90-second demo script

This is a recording script, not a completed video. Record the real public app. Leave live quote values as they appear; do not substitute invented prices or present an unconfirmed purchase as successful.

## Before recording

Open https://before-preipo.vividhub01.chatgpt.site in a desktop browser. Use a comfortably readable window, choose OpenAI, select $100, and refresh the quote. No wallet is needed. Wait for the quote to load before recording each result. If a provider returns an error, retry and record the recovered live state; do not describe an error state as a successful quote.

| Time | Show | Say |
| --- | --- | --- |
| 0–12 seconds | OpenAI company detail, including the catalog price and valuation. | “Before helps you understand a pre-IPO token purchase before you connect a wallet. A company name and a quoted token price are only the beginning.” |
| 12–30 seconds | $100 investment amount and the live buy/exit results. | “Enter an amount in USDC. Before gets a live buy quote, then asks what selling that exact token amount would return right now. You can see the entry and the potential exit together.” |
| 30–45 seconds | Select $5,000. Wait for the new quote, then point to the round-trip difference. | “Now change the order size. The quotes update from live liquidity. The difference makes execution costs visible before a purchase. These are independent quotes, not a promise of a future exit.” |
| 45–63 seconds | The valuation panel and entry-versus-catalog value. | “Before also translates your executable entry into an implied company valuation. It separates that from the issuer’s reference mark, which is a reference point—not a fair-value estimate.” |
| 63–78 seconds | Select SpaceX, return to $100, and wait for its quote. | “Under the hood, we verify PreStocks token addresses and read Solana token settings, including display adjustments. Transaction requests keep the original raw token units.” |
| 78–90 seconds | Return to a settled quote and the main interface. | “Before is built around PreStocks on Solana. Anyone can explore the analysis without a wallet. Know your entry. Understand your exit.” |

## Recording notes

- A simple screen recording with clear narration is enough; avoid spending time on effects.
- Do not show wallet recovery phrases, private keys, unrelated browser tabs, or account information.
- Capture the cursor selecting an amount and show the result after it loads.
- If network waits extend the recording, trim dead time without implying instant responses.
- Export a standard MP4. Upload to the video destination you choose and verify judge access.
- The official rules accept a live demo link on its own. A video is helpful, not required by the stated link rule.
